# 前端协作规则

- 当前是个人使用的极简版本，优先直白函数与现有 Vue、Element Plus 组件，不增加无必要的抽象和重复数据对象。
- 默认不增加业务参数校验、必填检查、长度或 URL 限制，不自动 trim 或改写输入；配置按输入原值提交，需要限制时再按明确需求添加。
- 流程列表只含概要，画布页单独读取完整定义。画布只检查显示所需的节点和连线结构，不增加业务校验；保存时保留扩展配置和坐标，不 trim 输入。无法解析的定义保留原文供修正，不用空画布覆盖。
- 提示词管理与流程节点使用分开维护：列表只读 ID、名称，编辑和详情单独读取完整正文；正文读取失败时禁止保存并提供重试入口，避免空值覆盖。名称和正文按原值提交，详情使用只读表单，新增与编辑共用表单。
- 流程编排采用全屏数据流，当前提供开始、大模型、收敛、返回节点；开始接收本次输入，大模型选择模型和可选提示词，收敛等待全部上游并收集结果。提示词下拉框分页读取概要，保存 config.prompt_config_id，不取正文；默认不选、允许清除，列表加载失败不自动改写已有选择。返回节点接收一个上游，原样作为接口返回，不能连接下游，无额外配置。大模型接收一个上游，文字直接传递，对象转为 JSON 文字。只展示返回节点的数据或错误，运行前保存当前画布，输入和结果不进入定义。
- 当前按全新业务版本维护，直接使用当前协议和字段，不保留历史节点、历史参数别名或迁移分支。
- 每个流程只有一个开始和一个返回节点：新流程默认各生成一个，由用户连线；已有时分别禁用工具箱按钮和拖拽，添加入口拦截重复，恰好各一个时才允许运行。返回节点隐藏输出圆点，连线入口也禁止它作为来源。允许删除后重新添加；其他支路可以独立结束，但本次运行仍等待所有支路完成。读取已有定义时不自动补返回节点，不增加其他字段校验。
- 流程定义顶层维护 start_node_id、return_node_id、nodes、edges。两个ID从当前画布响应式推导，保存时覆盖原定义中的对应ID，按钮删除、键盘删除和重新添加均同步，缺少节点的草稿使用 null；不增加额外配置输入框，不自动补齐缺少新字段的旧定义。上游关系和末端列表仍由后端根据连线计算，不重复存储。
- 流程运行输入固定为 text 与可选 user_id，使用 WorkflowInput 对象提交，不再包装为动态输入字段；开始节点配置区提供文字和可选用户ID，均只用于本次运行，不随画布保存或写入浏览器存储。返回结果 payload 可为文字、对象或列表，使用现有纯文本/JSON 展示，不额外解析或转换模型文字。
- 保留加载状态、防止重复提交、错误提示和现有删除确认；这些操作反馈不属于字段校验。
- API Key 不回显、不写浏览器存储；沿用后端统一返回，前端只显示配置是否有 Key。
- 关键参数和业务步骤使用便于初学者理解的中文注释。主要目录维护 README，行为变化时同步更新。
