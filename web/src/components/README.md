# 公共展示组件

`ChatPanel.vue` 提供问题输入、问答气泡、等待状态、错误提示和清空按钮。

- `disabled`：是否禁止发送，例如没有选择模型时。
- `submitQuestion(question)`：由页面传入的异步函数，接收当前问题并返回回答文本。
- `busy-change`：向页面报告发送状态，供页面锁定模型选择等操作。

组件不引用模型或流程接口，不关心具体调用目标，后续流程调试可复用同一输入与展示方式。气泡只存在组件内存中，不会作为历史消息传给提交函数，不写入浏览器存储。切换模型时页面通过 key 重新创建组件，导航离开或刷新也会清空。

失败时保留当前输入，可以再次点击发送重试；发送期间禁止重复提交和清空。回答以纯文本展示并保留换行，不直接渲染为 HTML。

个人极简版本不限制问题长度，不自动去除首尾空白，也不做空内容校验；是否接受这次输入由后端实际调用的 SDK 或模型服务决定。
