# 业务页面（个人极简版）

页面通过 Vue Router 切换，App.vue 保留应用外壳。

## 模型配置

ModelConfigs.vue 使用 Element Plus 的表格、表单、弹窗和分页。已经移除表单 rules、validate、必填检查、maxlength、URL 格式校验和自动 trim，输入内容按原值提交。接入方式既可选已有选项，也可手工填写，不在前端限制为枚举。

保留加载状态、防止重复请求、操作失败提示和删除确认，这些用于保证操作可理解，不对配置内容加业务限制。保存成功刷新列表；失败保留输入。模型配置不维护时间字段，列表不展示更新时间。

Key 不回显，编辑留空保留，填写新值替换，勾选清除则提交 null。后端也允许通过接口原样保存空字符串。列表和详情不读取密钥，页面只接收 has_api_key。

## 提示词配置

PromptConfigs.vue 使用现有 Element Plus 组件，提供概要分页、新增、编辑、只读详情和删除确认。新增使用空表单，编辑和详情按主键读取完整正文；isFormReady 在详情加载成功后才为 true，加载失败时禁止保存并提供重试入口。

名称和正文直接绑定 PromptConfigRequest，保持空白、换行和原始文字，不增加输入校验。保存失败保留表单，删除失败保留弹窗；保存、删除或读取正文时防止重复操作。列表刷新失败保留原列表，删除末页最后一条后退回有效页。该页仅维护提示词，不处理流程节点配置。

## 流程配置

WorkflowConfigs.vue 负责概要分页、画布入口和删除确认。WorkflowDesigner.vue 为全屏画布，读取完整定义，支持开始、大模型、收敛、返回节点的拖拽、连线、改名和保存；详情只读，可切换编辑。

新流程默认一个开始和一个返回节点，由用户连线；canAddNode 统一工具箱、拖拽和添加入口的唯一性判断。恰好各一个时才允许运行，删除后可重新添加。返回节点隐藏输出圆点，connectNodes 也禁止其作为连线来源。一个入口可以连接多条支路，其他支路可独立结束。

startNodeId、returnNodeId 根据当前画布响应式计算，保存时写入定义顶层的 start_node_id、return_node_id，不沿用 originalDefinition 中的旧ID。按钮删除、键盘删除、重新添加均自动同步，缺少对应节点时为 null；加载和保存保留扩展字段，不为缺少这两个字段的旧定义增加回退读取。

开始填写本次文字和可选用户ID，workflowInput.text、workflowInput.user_id 组成固定运行请求，用户ID仅供后续功能预留。大模型只选模型，收敛等待全部上游后按节点ID收集结果，返回节点原样输出一个上游，无额外配置。大模型接收一个上游，对象转为 JSON 文字，多路结果先接收敛节点。runWorkflow 先保存当前画布，再提交固定输入，只显示唯一返回节点的数据或公共错误。当前仍等待所有支路完成，不自动转为后台任务。运行中锁定编辑与重复提交；文字、用户ID和结果只存页面内存，不写入定义。问题在后端日志排查。

画布只检查显示所需结构，不 trim 或增加业务限制。节点配置、扩展字段和坐标按当前定义直接读写。无法解析的原文保留供修正，不以空图覆盖。列表删除前确认，末页清空后退回有效页码。


## 调试台

Playground.vue 分页加载全部已配置模型，选中模型后把提交函数交给公共 ChatPanel。每次只提交 model_config_id 与当前 question，不发送历史气泡。

ChatPanel 不限制问题长度，不 trim，也不以空内容为由阻止发送；模型或 SDK 不接受时直接显示返回错误。没有选中模型或请求正在执行时仍禁用发送。切换模型、清空、刷新或离开页面后清除气泡，不保存聊天记录。

默认不再添加前端输入限制或多套请求对象。新增页面和接口变化时同步更新本文档。
